# 留一格 · 旧物开箱：回忆收纳师

HTML + 原生 JavaScript + Canvas 2D 的可玩版本，1.0.1，2026-09-13。

## 试玩

- 直接用现代浏览器打开 `index.html` 即可；不需要联网或安装依赖。
- 推荐使用本地服务器，保持存档来源稳定：在此目录执行 `node serve.cjs`，打开 `http://127.0.0.1:8871`。
- 鼠标拖放或触屏拖放；也可以先点物品再点目标格。
- 选中后按 R 或点“旋转”；方向键移动预览，Enter 放下，Escape 取消。
- 单击仅选中，只有按住拖动才跟随鼠标；放下、失败或取消后停止跟随。
- 右键点击抽屉里的物品可直接取回桌面；该操作支持撤销。手机使用“放回桌面”按钮。
- 基础收纳、隔板抽屉、分区委托这几章：全部物品放入即可通关，不必填满，空格可以保留。
- 从**留物取舍**章节起难度逐关抬升：物品栏会涨到十几件（最多十八件，排成三行），并且**通关时最多只允许剩一格**。取舍关同理——但要先挑对「留哪几件」才凑得出格子数，只保证「至少有一种挑法能通关」，挑错可以退回来重挑。
- 「一点提示」每份委托自带一次，用完后看一段激励视频再得一次；「消除一件」同样看广告获得，可以把一件不必须、也没被委托人固定的旧物从这份委托拿掉（每份最多消两件）。算不出可消的件时会直接说明，不会让广告白看。
- 提示、撤销和重新整理免费。物品可从抽屉移回桌面。
- 通关后可以下载 PNG 作品图，图上带整齐度、分项拆解和图鉴进度。本次是本地导出，并未接入 TapTap 社区分享。
- 安卓手机可以装 `dist/liuyige.apk`（Android 7.0 及以上）。它跑在系统 WebView 里，和浏览器版是同一份文件，玩法完全一致。构建方式见 `node android/tools/build-apk.cjs`。

## 内容规模

100 份委托，分 8 个章节。开局是 7 关的**新手章节**：七种玩法各取一关、按最轻的难度呈现，先把“隔板、分区、取舍、固定件”这些规矩各认一遍，再进入各自的正式章节。前 50 关是**第一辑**，后 50 关是**第二辑**——同一章节里的第二辑关卡按春→冬推进，翻开委托簿能看出时间在走。

| 章节 | 关数 | 玩法 |
|---|---|---|
| 新手章节 | 7 | 七种玩法各一关，规则最轻 |
| 基础收纳 | 13 | 全部放入即可，可以留白 |
| 隔板抽屉 | 13 | 木色斜纹格不可占用 |
| 分区委托 | 13 | 指定物品须完整落在同名标记区 |
| 留物取舍 | 13 | 只能留一部分，配额固定；**从这一章起要求摆到只剩至多一格** |
| 隔板分区 | 14 | 隔板 + 分区叠加，同样要摆到只剩一格 |
| 取舍分区 | 13 | 取舍 + 分区叠加，同样要摆到只剩一格 |
| 大师委托 | 14 | 固定件不可移动，难度最高，同样要摆到只剩一格 |

物品栏件数也是从「留物取舍」正文起逐关抬升的：10 件 → 18 件（旧物一共 18 种，18 是硬顶）。超过 10 件时物品栏排成三行，靠缩小图标腾出第三行的位置。

委托簿里**每个章节单独编号**：列表序号是本章内部的顺序（隔板抽屉 13 关就编 01–13），不是全书序号。全书进度由顶栏的「X / 100 已整理」和信头的「87 / 100」表示。早先版本用的是全书序号，切到某一章会看到 13, 14, 15, 22, 23, 24, 52, 59… —— 中间全是被别章占掉的号，读起来像漏了关卡，已改掉。

18 种旧物全部至少在一份委托里出现过；多解：100 关都有两个以上合法答案。

### 难度曲线：从「留物取舍」起要求摆到只剩一格

**留物取舍**这一章的正文从 `drawer-16` 起（`drawer-15` 是该章的教学关，保持轻量），往后到 `drawer-100` 共 **82 关**，全部由 `tools/nearfull.cjs` 重新配过：物品格数总和与抽屉可用格数**恰好对齐**，摆完只剩 0~1 格；物品栏件数从 10 件线性抬到 18 件。前 18 关（含 7 关新手章节）沿用旧的增强表，仍是可以留白的入门难度。

- **不是简单堆件数。** 生成器先定「这份委托要放十到十八件」，再反过来挑抽屉尺寸与追加的旧物，让总和正好落在可用格数上（差 0 或 1）。每一关都要过真实求解器：可解、可完成、节点留足余量，并且**逐件固定后仍可解**——这一条是为「一点提示」准备的，提示要能在玩家已经摆了一半的盘面上继续给。
- **取舍关不能只顾盘面。** 玩家人手只放 `keepCount` 件，「能凑满格数」的挑法本来就少。所以生成器把件数当成未知量，对每块装得下的抽屉反解「挑任意几件恰好凑够」，并要求**至少 6 种挑法能通关**（实测多数在 20 种以上，drawer-47 有 90 种）。只保证有解，挑错可以重挑。
- **棋盘只能放大，不能缩到装不下原有隔板与分区。** 增强表只能覆盖尺寸与追加件，裁掉的隔板／分区在运行时不会跟着消失，所以生成器加了一道闸：新尺寸必须装得下原有的全部隔板与分区格。
- **近满盘对求解器反而更友好。** 约束越强，MRV 剪枝越有效：18 件填满 9×8 只要 590 节点 / 18ms。全量 82 关里最坏的一关也在 6 万节点预算内。

第二辑（第 51–100 关）原先靠**形状别扭度 + 条件叠加**（隔板／分区／取舍同时出现）加难度、件数反而收窄；现在件数上限放开到 18，两套手段叠在一起用。批次装配脚本见 `tools/nearfull.cjs` 与 `tools/apply-nearfull.cjs`，成品规格见 `tools/nearfull-report.txt`。

## 特色系统

**新手章节。** 不按“第 1 关最简单”排序，而是从每种玩法里各抽一关，把规则一次认全。其余关卡解锁后按玩法分章排列。

**整齐度（随摆随算）。** 三部分加权：对齐 45%、留白 30%、居中 25%。

- **对齐**：每件旧物的四条边，能和抽屉边或另一件旧物共线就记一分。
- **留白**：空位应该推到边上或靠住隔板，别在物品中间挖洞。看的是空位的去向，不是空位的数量。
- **居中**：整体不要全堆在一角。

分数只作参考，不设星级门槛——各关的可达上限并不一样（离线实测最低的一关也能爬到 84，最高 100，评语线因此定在 82）。所以给的是**一句评语 + 一条“下一步动什么”的建议**，而不是一个够不到的星星目标。

**回忆图鉴。** 24 段旧物关系，把两件相关的旧物按特定方式摆在一起就会解锁。四种关系：挨在一起、并排、上下摞着、各靠一边。解锁写进本机存档，同一段只记一次。图鉴面板只在第一次打开时构建。

**背景音乐（现场合成，没有音频文件）。** 八小节循环 32 秒，60 BPM：慢起的暖垫（Dmaj9 → Bm7 → Gmaj7 → A7sus4 走两遍）+ 稀疏的音盒主旋律 + 每小节两下的低音。空拍比音符多，是背景不是主角。

- 用 Web Audio 现场合成，**不挂 mp3**。理由有三：这是一个纯静态、零构建、双击就能玩的页面，几 MB 的音频文件会让首屏和离线包都变笨重；合成不占体积，循环处相位连续，没有接头爆音；也不牵扯音乐授权。
- 浏览器要求音频必须由用户手势启动，所以**第一次点画面或按键才开始响**，不在加载时打扰人。
- 右上角「声音」一个开关同时管 BGM 和提示音，选择记进本机存档、下次打开沿用。
- 切到别的标签页会自动淡出，回来再接上。
- 提示音和 BGM 共用同一个 `AudioContext`；关闭时先淡出 1 秒再收声，不会有硬切。

## 当前限制

- 这是浏览器可玩的本地版本，不是已上线的 TapTap 游戏。
- **APK 尚未在真机上启动过。** 这台机器没有安卓设备也没有模拟器，能验证的是包结构完整、游戏文件与源文件逐字节一致、签名有效、清单字段正确；WebView 里的实际渲染与触摸手感待真机确认。首次安装重点看白屏、BGM 起播、拖动会不会被页面滚动抢走、杀进程后存档还在不在。
- APK 与小游戏两个渠道若同时发布，官方要求接入 TapTap 登录并打通两边存档，目前还没做；当前 APK 的存档只在手机本机。
- 未接入 TapTap 登录、平台存档、支付、平台分享或其他发布必接能力；没有真实收费。
- **激励视频已接好适配层，但广告位还没申请。** `ads.js` 里的 `AD_UNIT_ID` 是空字符串，按「未接入」处理——提示与消除都会直接放行，玩家不会因为拿不到广告卡住。要到 TapTap 开发者后台（或 Dirichlet 媒体管理平台）建好「激励视频」广告位、把 ID 填进去，才会真的走广告；`STRICT` 开关决定拿不到广告时给不给奖励。
- **TapTap「H5 快速上架」（WebView 承载）里有没有 `tap` 全局对象，尚未确证。** 官方文档目前只覆盖 JS VM 小游戏，所以 `ads.js` 按「拿不到就降级」写：网页版、WebView 版都能正常玩，只是没有广告变现。真机接入前需要在目标渠道里实测一次 `typeof tap`。
- 数据仅保存在当前浏览器同一来源的本机存储中，不能跨设备同步。清理站点数据会删除存档。
- 本地事件记录只用于调试，最多200条，不上传网络；不能据此声称已有留存或变现成绩。
- 100 关用于看内容消耗与玩法变化，仍不能验证 D7／D30。整齐度的口径和上限是离线实测出来的，换关卡后需重跑 `tools/ceiling.cjs` 与 `tools/gradient.cjs`。
- 整齐度有一处已知短板：93 关非教学关里有 39 关，**朴素摆法**（求解器的左上贪心解）本身就有 95 分以上，认真摆也只好 1–4 分。这些关的分数几乎不动，玩家感受不到「再整一整」的空间。这是评分口径问题（各关可达上限不同），不是关卡问题，且第二辑比第一辑更轻（梯度中位 9 对 6）。改法见 `NEXT_VERSION_PROPOSAL.md` 的「按关卡自身上限归一化」。
- 作品与文案为本次制作；物品当前使用程序插画，正式版可替换为统一规格的手绘素材。
- 背景音乐是现场合成的，音色由浏览器实现决定，不同设备听感会有差异；只有开关、没有音量滑杆。**首次进入要在页面上点一下才会响**——这是浏览器的自动播放策略，不是故障。iOS 静音开关拨到静音时，Web Audio 也会没声。
