# docs/

这个目录里是两类完全不同的东西，别混着看：

## 要发布到公网的（GitHub Pages 的站点根目录）

| 文件 | 说明 |
|---|---|
| `privacy.html` | **《留一格》隐私政策正文**，TapTap 审核要填的那个链接就指向这里 |
| `privacy.css` | 上面那份页面唯一的样式表。刻意不和游戏的 `style.css` 共用 |
| `privacy.md` | 同一份正文的 Markdown 版，方便在仓库里 review 与 diff |

Pages 的 Source 选 `v1` 分支 + `/docs` 目录，公网地址是：

```
https://luffryfight.github.io/liuyige/privacy.html
```

开启步骤与「为什么样式要单独抄一份」写在根目录的 `TAPTAP_UPLOAD.md`（第七之二节）。

## 只作参考、不对外发布的

| 文件 | 说明 |
|---|---|
| `privacy-policy-template.docx` | **第三方隐私政策模板**（上海网络游戏行业协会风格的通用游戏类模板）。仅作撰写参考留档，**不是**本项目的政策，也不要在任何界面里引用它 |

这份模板跟最终政策差得很远：它是面向「有账号体系、有实名认证、有充值、接了多个第三方 SDK」的游戏写的，
章节里大量是注册登录、支付、设备权限、广告联盟那一套；而《留一格》没有账号、没有内购、不联网、
不申权限、不接 SDK，所以最终政策里**绝大多数章节都被删掉或改成了「不存在」的说明**。

留这份模板的用处是：将来如果游戏真的加了账号或广告，可以照它补齐对应章节的写法。

> `docs/` 下的内容不会被打进游戏包：H5 打包器（`tools/pack-taptap.cjs`）和 APK 打包器
> （`android/tools/build-apk.cjs`）都走**白名单**，只收那 7 个运行时文件。
